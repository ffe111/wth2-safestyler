# แผนชุดกฎแปลงคำไทยเป็นคำไทยผสมอักษร

เอกสารนี้บันทึกแผนก่อนพัฒนา ดู [README ของโปรเจกต์](../README.md) เพื่อเริ่มใช้ MVP และดู [ชุดกฎที่เครื่องมือใช้งานจริง](../packages/converter/src/rules.ts) สำหรับข้อมูลปัจจุบัน ชุดตัวอย่างมาจากข้อความที่ผู้ใช้ให้ ไม่ใช่รายการคำต้องห้ามของแพลตฟอร์ม และไม่ได้ทดสอบว่าจะผ่านการตรวจของแพลตฟอร์มหรือไม่

## 1. ผู้ใช้ควรเห็นอะไร

- วาง `ฉันมีเงินแล้ว` แล้วกดแปลง ได้ `ฉันมีเงิuแล้ว` พร้อมรายการคำที่เปลี่ยน
- วาง `เปิดประมูล` ได้ `Iปิดปsะมูa` หากเปิดทั้งหมวดคำทั่วไปและหมวดการค้า
- วาง `เงินเดือนและเงิน` ได้ `เงินเดือนและเงิu` ตามค่าเริ่มต้นที่เก็บ `เงินเดือน` เป็นคำคงเดิม ตัวอย่างนี้กำหนดพฤติกรรมของโปรเจกต์ ไม่ได้บอกว่าคำไหนถูกแพลตฟอร์มห้าม

หน้าเว็บรับข้อความและแสดงผล ไม่เก็บสำเนาชุดกฎ ไม่ส่งข้อความไปเซิร์ฟเวอร์ในรุ่นแรก และไม่โพสต์แทนผู้ใช้

## 2. จัดหมวดสองแกน

**แกนความหมาย** ใช้หาและเลือกชุดคำ ไม่ใช้ตัดสินว่าอักขระใดจะถูกเปลี่ยน คำหนึ่งติดหลายป้ายได้ แต่มีรายการกฎต้นทางรายการเดียว

| หมวด | ตัวอย่างตั้งต้น | ชายขอบที่ต้องทบทวน |
|---|---|---|
| การเงินและทรัพย์สิน | เงิน, ทองคำ, ทรัพย์ | เงินเดือน, ทรัพย์สิน เป็นคำของตัวเอง กำหนดผลแยกจากคำสั้น |
| การค้าและกิจกรรม | ประมูล | เปิดประมูล อาจประกอบจากสองกฎ หรือมีกฎวลีหากต้องการผลต่างออกไป |
| โชคลาภและคำอวยพร | โชคลาภ, เฮงๆ, รวยๆ | เฮง กับ เฮงๆ ไม่ถือเป็นรายการเดียวกันโดยอัตโนมัติ |
| บุคคลและสถานะ | เศรษฐี | ชื่อบุคคล ชื่อร้าน ชื่อสถานที่ต้องระวังเป็นกรณีแยก ไม่อนุมานว่าเป็นชื่อจากข้อความทุกครั้งได้ |
| ชีวิต ความปลอดภัย และการคุ้มครอง | ตาย, แคล้วคลาด, ปกป้อง, กันภัย | ตายตัว และกันภัยในชื่อเฉพาะเป็นกรณีที่ต้องกำหนดผลให้ชัด |
| ความเชื่อและสำนวน | ผี, แก้กัน, คุณไสย มนต์ดำ, ลมเพลมพัด | เก็บรูปที่มีที่มา ไม่ขยายจากคำเดียวไปหาคำพ้องหรือสำนวนอื่นเอง |
| สัตว์ | เสือ, สิงห์, งูพิษ, สัตว์เลื้อยคลานมีพิษ | เสือ กับ มะเขือ ไม่เกี่ยวกัน สิงห์อาจเป็นชื่อหรือคำเรียกสัตว์ และตัวแปลงไม่เดาจากบริบทในรุ่นแรก |
| คำทั่วไป | เปิด | การเปิด, เปิดร้าน, เปิดใจ ต้องตกลงว่าจะเปลี่ยนส่วนประกอบหรือคงคำที่กำหนดไว้ |

**แกนรูปคำ** ใช้กำหนดว่าต้องทดสอบขอบเขตแบบใด ไม่ต้องวิเคราะห์ชนิดคำทุกคำระหว่างแปลง

| รูปคำ | ตัวอย่าง | พฤติกรรมที่ต้องกำหนด |
|---|---|---|
| คำเดี่ยว รวมคำนาม คำกริยา และคำบอกลักษณะหรืออาการ | เงิน, ผี, เปิด, ตาย; เฮง และรวยเป็นคำฐาน | แปลงเมื่อมีรายการตรงรูปและอยู่ที่ขอบคำ รุ่นแรกมี เฮงๆ และรวยๆ ไม่ได้ลงทะเบียนคำฐานโดยอัตโนมัติ |
| คำหลายพยางค์ คำประสม และคำยืม | ทองคำ, โชคลาภ, งูพิษ, เศรษฐี | ยอมให้รายการเดียวครอบหลายโทเคนของตัวตัดคำโดยไม่ต้องเดาว่าตัวตัดคำจะคืนหนึ่งโทเคน |
| คำซ้ำและไม้ยมก | เฮงๆ, รวยๆ | เก็บ `ๆ` และช่องไฟตามต้นฉบับ รองรับ `เฮง ๆ` ก็ต่อเมื่อบันทึกรูปนั้นเพิ่ม |
| คำซ้อน สำนวน และวลี | แคล้วคลาด, ลมเพลมพัด, คุณไสย มนต์ดำ | ใช้รายการตรงรูป วลียาวสุดชนะเมื่อเริ่มที่ตำแหน่งเดียวกัน ไม่จับข้ามบรรทัดโดยปริยาย |
| ชื่อเฉพาะ คำทับศัพท์ คำย่อ และข้อความผู้ใช้ระบุให้คงเดิม | ชื่อร้าน, ชื่อแบรนด์, ตัวย่อ | เริ่มจากรายการคงเดิมที่ระบุได้ชัด ไม่อ้างว่าระบุชื่อเฉพาะได้ครบ และไม่ขยายกฎไปยังคำที่คล้ายกัน |
| คำไวยากรณ์และตัวเลข | ฉัน, และ, ที่, ใน, จะ, ไม่, คน ใน `3 คน` | ไม่เปลี่ยนโดยอาศัยชนิดคำ เก็บเป็นเคสไม่เปลี่ยนเพื่อกันการแทนตัวอักษรทั้งย่อหน้า |

ป้ายกำกับรูปคำให้หลายค่าได้ ส่วนระดับการจับมีเพียงรายการข้อความตรงรูปที่ครอบหนึ่งคำหรือหลายคำ ไม่ต้องสร้างตัววิเคราะห์ไวยากรณ์อีกตัว

## 3. กำหนดรูปการเปลี่ยนอักขระ

| รูปแบบ | ตัวอย่างจากข้อมูล | นโยบายรุ่นแรก |
|---|---|---|
| ไทยหนึ่งตัวเป็นอังกฤษหนึ่งตัว | `น → u`, `อ → o`, `ล → a`, `ร → s`, `พ → w`, `ง → v`, `ย → E`, `เ → I` | ใช้เป็นแนวทางให้คนเขียนกฎ ไม่ใช่ตารางที่เครื่องมือวิ่งแทนทั้งข้อความ คงตัวพิมพ์เล็กและใหญ่ตามผลที่บันทึก |
| ไทยหนึ่งตัวเป็นอังกฤษหลายตัว | `แ → II` | `II` คือ I พิมพ์ใหญ่สองตัว ไม่ใช่ l หรือตัวเลข 1 รองรับความยาวผลลัพธ์ที่เปลี่ยน |
| อังกฤษตัวเดียวใช้แทนไทยคนละตัว | `พ → w` และ `ผ → w` ใน `ผี → wี` | `ผ → w` เป็นการอ่านจากตัวอย่าง `wี` ไม่ใช่กฎทั่วคลัง คงเป็นข้อยกเว้นรายคำ |
| เปลี่ยนหลายตำแหน่งในคำ | `ทรัพย์ → ทsัwย์`, `กันภัย → กัuภัE` | บันทึกผลลัพธ์ทั้งคำ ให้สระ วรรณยุกต์ และทัณฑฆาตที่ไม่ถูกระบุให้เปลี่ยนคงอยู่ |
| เปลี่ยนรูปสระนำแต่ไม่แตะสระหรือเครื่องหมายตำแหน่งอื่น | `เปิด → Iปิด`, `แก้กัน → IIก้กัu` | ใช้ผลลัพธ์ตรงตามที่อนุมัติ ทดสอบการแสดงผลจริงด้วยฟอนต์หลายแบบ ไม่อ้างว่าอักขระดูเหมือนกันทุกจอ |
| เลข สัญลักษณ์ อักขระจากระบบเขียนอื่น และอักขระซ่อน | ไม่มีในชุดตั้งต้น | ไม่เพิ่มอัตโนมัติ รุ่นแรกจำกัดผลลัพธ์ใหม่เป็นอักษรไทยและอังกฤษ พร้อมเครื่องหมายและช่องไฟเดิม ไม่สร้างอักขระซ่อน |

ทางเดียวเท่านั้น ไม่รับรองการถอดกลับ เพราะ `w` แยกกลับไม่ได้เสมอว่าเป็น `พ` หรือ `ผ` และ `I` อาจมีอยู่แล้วในข้อความเดิม

## 4. บัญชีตัวอย่างตั้งต้นและสถานะ

ตารางนี้เป็นรายการรอตรวจ ไม่ใช่ข้อมูลที่เครื่องมืออ่าน ในตอนสร้างชุดกฎให้เก็บต้นฉบับที่เครื่องมืออ่านได้เพียงแห่งเดียว แล้วสร้างตารางเอกสารจากข้อมูลนั้น

| ต้นฉบับ | ผลที่ต้องการ | หมายเหตุ |
|---|---|---|
| เงิน | `เงิu` | มีเคส `เงินเดือน` และ `เติมเงิน` ประกบ |
| ทองคำ | `ทoงคำ` | ไม่เปิดกฎ `ทอง` เอง |
| โชคลาภ | `โชคaาภ` | คำประสม |
| ทรัพย์ | `ทsัwย์` | คงทัณฑฆาต |
| เศรษฐี | `เศsษฐี` | ไม่ขยายไปหา `เศรษฐกิจ` |
| เฮงๆ | `เฮvๆ` | คงไม้ยมก |
| รวยๆ | `sวยๆ` | คงไม้ยมก |
| ตาย | `ตาE` | ทดสอบ `ตายตัว` แยก |
| แคล้วคลาด | `แคa้วคaาด` | ตรงตัวอย่าง แม้มี `แ` ที่เปลี่ยนเป็น `II` ได้ในคำอื่น |
| ปกป้อง | `ปกป้oง` | ตรงตัวอย่าง ไม่เปลี่ยน `ง` เป็น `v` เพิ่ม |
| เปิด | `Iปิด` | คงตัว I พิมพ์ใหญ่ |
| ประมูล | `ปsะมูa` | เปลี่ยนสองตำแหน่ง |
| ผี | `wี` | อนุมานต้นฉบับจากรูปผลลัพธ์ ให้ยืนยันก่อนเปิดในชุดหลัก |
| แก้กัน | `IIก้กัu` | ถอดตามตัวอย่าง ไม่แก้เป็น `แก้กรรม` เอง |
| กันภัย | `กัuภัE` | เปลี่ยนสองตำแหน่ง |
| คุณไสย มนต์ดำ | `คุณไสE มuต์ดำ` | รุ่นแรกทดสอบเป็นวลีเดิมก่อน ถ้าจะรองรับแต่ละคำแยกให้เพิ่มรายการชัดเจน |
| ลมเพลมพัด | `aมเพaมพัด` | ตรงตัวอย่าง ไม่เปลี่ยน `พ` เพิ่ม |
| เสือ | `เสืo` | มาจากตัวอย่าง `เสือ & สิงห์` ทดสอบการคง ` & ` |
| สิงห์ | `สิvห์` | คงทัณฑฆาต |
| งูพิษ | `vูwิษ` | `v` แทน `ง` และ `w` แทน `พ` |
| สัตว์เลื้อยคลานมีพิษ | `สัตว์เลื้oยคลาuมีwิษ` | วลีต่อเนื่องไม่เว้นวรรค คงสระและเครื่องหมายเดิม |

## 5. รูปข้อมูลและขอบเขตโมดูล

เลือก **พจนานุกรมรายคำและรายวลี** เป็นแหล่งความจริง มีผลลัพธ์ชัดเจนต่อรายการ เทียบกับอีกแบบคือ **สร้างผลจากตารางตัวอักษรและตำแหน่งที่จะเปลี่ยน** แบบหลังกระชับเมื่อกฎสม่ำเสมอ แต่ต้องเก็บตำแหน่งและข้อยกเว้น เช่น `แคล้วคลาด` ไม่ได้เปลี่ยน `แ` และ `ลมเพลมพัด` ไม่ได้เปลี่ยน `พ` ตามตารางหลัก พจนานุกรมตรวจผลทั้งคำได้ง่ายกว่า จึงเก็บตารางอักขระไว้เพื่อช่วยร่างกฎเท่านั้น ไม่มีตัวประมวลผลสองแบบให้ผู้ดูแลเลือกใช้

```ts
// สัญญาที่เสนอ ยังไม่ใช่โค้ดที่ใช้งานได้
type Rule = {
  id: string;
  exact: string;
  categories: readonly CategoryId[];
  forms: readonly FormId[];
  sourceNote: string;
  status: 'draft' | 'reviewed';
} & ({ action: 'replace'; output: string } | { action: 'keep' });

type Edit = {
  from: number; // UTF-16 offset ในข้อความต้นฉบับ
  to: number;   // ไม่รวมตำแหน่งปลาย
  original: string;
  output: string;
  ruleId: string;
};

declare function convertThai(
  text: string,
  options?: { categories?: readonly CategoryId[] }
): { text: string; edits: readonly Edit[] };
```

- `rules/` เป็นเจ้าของหมวดและรายการกฎ ตรวจ ID ซ้ำ ข้อความต้นทางซ้ำ ชื่อหมวดไม่รู้จัก รูปมีช่องว่างหัวท้าย และรายการแปลงที่ไม่เปลี่ยนอะไร กฎที่ยังเป็น draft ไม่เข้าเอนจิน
- `src/converter/` เป็นเจ้าของการจับขอบคำ การกันช่วงที่ไม่แก้ การเลือกกฎเมื่อทับกัน และการสร้าง `edits` ดึงรายการจาก `rules/` แล้วสร้างดัชนีตามอักขระต้นครั้งเดียว ไม่ให้หน้าเว็บเห็นโครงสร้างดัชนีหรือกฎการตัดคำ
- `src/web/` เรียกแปลงหนึ่งครั้งแล้วแสดงผลและรายการแก้ไข ใช้ข้อความธรรมดาในการแสดง ไม่ใช้ HTML ที่มาจากผู้ใช้
- `tests/fixtures/` เก็บประโยคทดสอบพร้อมผลที่คาดหวัง แยกจากรายการกฎ เพื่อให้เทสต์จับการเปลี่ยนผลโดยไม่ตั้งใจได้

## 6. ลำดับตัดสินเมื่อคำติดกัน

1. กันช่วง URL, อีเมล, `@mention` และ `#hashtag` ก่อนโดยค่าเริ่มต้น ไม่ให้การแทนคำทับแม้บางส่วน ข้อความปกติหลังช่วงนั้นยังแปลงได้
2. ใช้ `Intl.Segmenter('th')` หาแนวขอบคำ ไม่ใช้การเว้นวรรคหรือ regex `\b` เป็นตัวแทนขอบคำไทย จับข้อความกฎตามตัวอักษรและตรวจเฉพาะขอบทั้งสองด้าน จึงรองรับวลีที่ครอบหลายโทเคนได้ ถ้าเบราว์เซอร์ไม่รองรับ ให้แจ้งและคงข้อความเดิม ไม่ถอยไปค้นสตริงย่อย
3. เตรียมรายการ `keep` ที่ตรวจแล้วเป็นช่วงคงเดิมก่อนเลือกกฎแปลง เช่น `เงินเดือน` และ `ตายตัว` รายการคงเดิมมีผลแม้ปิดบางหมวด จากนั้นเลือกกฎซ้ายไปขวา ถ้าเริ่มที่ตำแหน่งเดียวกันให้รายการยาวกว่าชนะ ไม่ให้สองกฎแก้ช่วงเดียวกัน ตัวเลือกหมวดกรองเฉพาะกฎแปลงก่อนตัดสินลำดับ
4. แปลงจากข้อความต้นฉบับหนึ่งรอบเท่านั้น ไม่วนหาคำใหม่จากผลที่เพิ่งสร้าง เก็บส่วนที่ไม่ได้แก้เหมือนเดิมทุกอักขระ กรณีสระหรือวรรณยุกต์สะกดเป็นคนละลำดับ Unicode ให้คงเดิมหรือเพิ่มรูปที่ตรวจแล้วเป็นรายการแยกในรุ่นแรก ไม่ normalize ข้อความทั้งก้อน

ลองตรวจขอบคำด้วย Node v26.13.0 แล้วพบว่า `เงินเดือน` ถูกแยกเป็น `เงิน` กับ `เดือน` จึงต้องมีกฎคงเดิมถ้าต้องการรักษาคำประสมนี้ ส่วน `เปิดประมูล` ก็ถูกแยกเป็น `เปิด` กับ `ประมูล` และ `คุณไสย มนต์ดำ` ถูกแยกเป็น `คุณ` `ไสย` ช่องว่าง `มนต์` `ดำ` นี่เป็นผลทดสอบตัวตัดคำบนเครื่องเดียว ยังไม่ใช่ผลของตัวแปลงหรือการทดสอบข้ามเบราว์เซอร์

## 7. ลงชุดกฎและตรวจความครอบคลุม

1. **ตรวจชุดตั้งต้น** ให้แต่ละรายการมีที่มา หมวด รูปที่ต้องการ ผลที่ต้องคงเดิม และผู้ยืนยันก่อนเปลี่ยนสถานะเป็น `reviewed` รายการที่ใกล้กันมาก เช่น คำฐานกับคำซ้ำ ให้ตัดสินแยกกัน งานชุดแรกเสร็จเมื่อทุกแถวมีผลตัดสินว่าจะเปิดใช้ คงเป็น draft หรือไม่รับ
2. **เพิ่มเคสประโยคจริง** กฎแปลงแต่ละรายการมีอย่างน้อยหนึ่งเคสตรงคำและหนึ่งเคสที่จำลองความเสี่ยง เช่น คำซ้อน คำประสม ช่องว่าง หรือ URL หมวดใดมีแต่ตัวอย่างคำโดดถือว่ายังไม่ครอบคลุม ให้คนอ่านภาษาไทยทบทวนทั้งความอ่านรู้เรื่องและคำที่ถูกเปลี่ยนเกินกฎ
3. **ทดสอบเอนจินก่อนมีเว็บ** ใช้เคสข้างล่างตรวจผลเต็มประโยคและตำแหน่งแก้ไข ทดสอบกฎทับกัน การเลือกหมวด อินพุตว่าง emoji ขึ้นบรรทัดใหม่ ตัวละตินเดิม และอักขระผสม ทดสอบช่วง `edits` ว่าไม่ทับกันและประกอบกลับได้เท่ากับผลจริง
4. **ทดสอบบนเว็บเป้าหมาย** ตรวจขอบคำและการวางสระต่างฟอนต์บนเดสก์ท็อปและมือถือ ทดสอบวางข้อความ กดแปลง และคัดลอกให้ตรงผลบนหน้าเว็บ หาก runtime ตัดคำต่างกันจนไม่ผ่านเคสที่กำหนด ให้แก้ที่ตัวจับขอบคำหรือกฎเฉพาะ พร้อมเพิ่มเคส ไม่เพิ่มการจับคำย่อยทั่วระบบ

| อินพุต | ผลที่คาดในชุดทดสอบ | เหตุผล |
|---|---|---|
| `เงินเดือนและเงิน` | `เงินเดือนและเงิu` | `keep` ทับกฎย่อย |
| `เติมเงินแล้ว` | `เติมเงิuแล้ว` | ข้อเสนอให้แปลงส่วนที่ตัวตัดคำแยกได้เมื่อไม่มีกฎคงเดิม |
| `มะเขือ ไม่ใช่เสือ` | `มะเขือ ไม่ใช่เสืo` | ไม่แทนตัว `อ` ทั้งประโยค |
| `ผีเสื้อ กับ ผี` | `ผีเสื้อ กับ wี` | หลังอนุมัติกฎ `ผี` ให้ทดสอบว่าคำที่ตัดไม่ได้เป็น `ผี` เดี่ยวต้องคงเดิม |
| `ตายตัว แต่ต้นไม้ตาย` | `ตายตัว แต่ต้นไม้ตาE` | คำเดิมต่างบริบทตามรายการคงเดิม |
| `เฮงๆ เฮง ๆ เฮง` | `เฮvๆ เฮง ๆ เฮง` | เปิดเฉพาะรูปที่บันทึก |
| `คุณไสย มนต์ดำ` | `คุณไสE มuต์ดำ` | วลีมีช่องว่างและหลายโทเคน |
| `เสือ & สิงห์ 😊` | `เสืo & สิvห์ 😊` | คงเครื่องหมาย ช่องไฟ emoji และทัณฑฆาต |
| `#ทองคำ @เงิน https://example.org/เงิน เงิน` | `#ทองคำ @เงิน https://example.org/เงิน เงิu` | ไม่แก้ในข้อความที่ทำหน้าที่เป็นลิงก์หรือชื่ออ้างอิง |
| `ทoงคำ และ ทองคำ` | `ทoงคำ และ ทoงคำ` | คงรูปที่แปลงแล้วและเปลี่ยนเฉพาะรูปปกติ |
| `😊 เงิน` | `😊 เงิu` | `edits[0]` ครอบช่วง `[3,7)` ใน UTF-16 |

**ยังไม่ทำในรุ่นแรก:** การเดาคำใหม่ การสุ่มตัวแทน การสร้างรูปจากตารางอัตโนมัติ การถอดกลับ และการวัดว่าข้อความผ่านการตรวจของแพลตฟอร์มหรือไม่ ขั้นต่อไปหลังตกลงนโยบายคำประสมคือทำรายการกฎที่เครื่องมืออ่านได้กับ fixtures ก่อนสร้างหน้าเว็บ
