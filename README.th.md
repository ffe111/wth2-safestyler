# SafeStyler · ไทยผสมอักษร

[English](README.md) · [API ของตัวแปลง](packages/converter/README.md)

SafeStyler เป็นเครื่องมือแปลงคำไทยที่เลือกไว้ให้เป็นรูปสะกดที่ผสมอักษรไทยกับอักษรละติน ใช้เว็บเพื่อดูว่าคำไหนเปลี่ยนก่อนคัดลอกผล หรือเรียกไลบรารี TypeScript เพื่อใช้กฎเดียวกันในโค้ดของคุณ

| ข้อความต้นฉบับ | ผลลัพธ์ |
| --- | --- |
| `รับเงินสดล้วน ๆ` | `รับเงิuสดล้วน ๆ` |
| `เงินเดือนและเงิน` | `เงินเดือนและเงิu` |
| `#เงินสด เงินสด` | `#เงินสด เงิuสด` |

SafeStyler จับเป็นรายคำและรายวลี ไม่ได้แทนทุกตัวอักษรที่ตรงกัน เว็บประมวลผลข้อความในเบราว์เซอร์ของคุณโดยไม่ส่งไปยังเซิร์ฟเวอร์ ชุดกฎนี้ไม่ใช่รายการคำต้องห้ามของแพลตฟอร์ม และผลลัพธ์ไม่รับประกันผลการตรวจของแพลตฟอร์มใด

## เปิดเว็บในเครื่อง

ใช้ Node.js ตั้งแต่ 20.19 ในสาย 20.x หรือใช้ Node.js ตั้งแต่ 22.12 ขึ้นไป

```sh
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดง พิมพ์หรือวางข้อความไทย หรือกด **ใส่ตัวอย่าง** เพื่อโหลดข้อความตัวอย่าง เลือกหมวดที่ต้องการแล้วกด **แปลงข้อความ** ดูรายการใน **คำที่เปลี่ยน** จากนั้นกด **คัดลอกผลลัพธ์**

## เรียกตัวแปลงจาก TypeScript

เว็บนำเข้า `@thai-word-styler/converter` จาก npm workspace ใน repo นี้ แพ็กเกจยังไม่เผยแพร่บน npm ก่อนนำเข้าแพ็กเกจในเครื่อง ให้รัน `npm run build` จากโฟลเดอร์หลักของ repo

```ts
import { convertThai } from '@thai-word-styler/converter';

const result = convertThai('เงินเดือนและเงิน', { categories: ['finance'] });

console.log(result.text); // เงินเดือนและเงิu
console.log(result.edits.map(({ original }) => original)); // ['เงิน']
```

[เอกสาร API ของตัวแปลง](packages/converter/README.md) อธิบายผลลัพธ์ ข้อกำหนดของสภาพแวดล้อมที่ใช้รัน และวิธีเพิ่มกฎ

## สร้างและทดสอบโปรเจกต์

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

เทสต์เว็บใช้ไฟล์ที่ build สำหรับเผยแพร่ และรันบน Chromium ด้วยโปรไฟล์เดสก์ท็อปและมือถือจำลอง หากต้องการ build โดยไม่รันเทสต์เว็บ ให้ใช้ `npm run build` ไฟล์เว็บอยู่ที่ `apps/web/dist/` และไม่ต้องใช้ backend
